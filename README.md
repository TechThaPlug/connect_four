# Connect Four

A two-player command-line Connect Four game built with Ruby.

## Features

- Two-player gameplay
- 6-row by 7-column board
- Horizontal, vertical, and diagonal win detection
- Draw detection
- Invalid move handling
- Automated RSpec tests

## Requirements

- Ruby
- Bundler

## Installation

Run:

    bundle install

## Play

Run:

    ruby main.rb

Players take turns choosing columns 1–7. The first player to connect four tokens wins.

## Tests

Run:

    bundle exec rspec

## Code quality

Run:

    bundle exec rubocop
